# PAJ7620U2手势识别传感器功能说明

## 概述
本项目已为ESP32-S3N16R8-EMOJI开发板集成了PAJ7620U2手势识别传感器功能。该传感器与SSD1306显示屏共用I2C总线（SDA: GPIO41, SCL: GPIO42），通过手势控制舵机运动。

## 硬件连接
PAJ7620U2传感器与SSD1306显示屏共用相同的I2C引脚：

| PAJ7620U2引脚 | ESP32 S3 N16R8引脚 | 说明 |
|------------|---------------------|------|
| VCC        | 3.3V                | 电源正极 |
| GND        | GND                 | 电源负极 |
| SCL        | GPIO42              | I2C时钟线（与显示屏共用） |
| SDA        | GPIO41              | I2C数据线（与显示屏共用） |
| INT        | 悬空              | 中断引脚（未使用） |

## 手势动作映射

### 基本手势
- **向左手势** → 舵机左转
- **向右手势** → 舵机右转  
- **向上手势** → 舵机抬头
- **向下手势** → 舵机低头
- **向前手势** → 舵机回中心位置

### 连续手势
- **连续左右摆动**（至少3次交替） → 舵机摇头动作
- **连续上下摆动**（至少3次交替） → 舵机点头动作

## 技术实现

### 核心文件
1. `gesture_sensor.h` - 手势识别传感器头文件
2. `gesture_sensor.cc` - 手势识别传感器实现文件
3. `emoji_board.cc` - 主板文件（已集成手势功能）

### 关键特性
1. **I2C总线共享**：与SSD1306显示屏安全共用I2C总线
2. **实时检测**：50ms检测间隔，响应迅速
3. **连续手势识别**：智能识别摇头、点头等复合动作
4. **超时机制**：2秒超时自动重置手势序列状态
5. **错误处理**：完善的初始化失败处理机制

### 代码架构
```
GestureSensor类
├── Initialize() - 初始化传感器
├── ReadGesture() - 读取手势数据
├── ProcessGesture() - 处理单个手势
├── CheckSequentialGestures() - 检测连续手势
├── StartGestureTask() - 启动检测任务
└── StopGestureTask() - 停止检测任务
```

## 使用说明

### 自动启动
系统启动后，手势识别功能会自动初始化并开始工作。如果初始化失败，会在日志中显示错误信息。

### 手势操作
1. 将手掌放在传感器前方约5-15cm处
2. 做出相应手势动作
3. 观察舵机的对应运动

### 连续手势操作
1. **摇头**：连续做左-右-左或右-左-右手势（至少3次交替）
2. **点头**：连续做上-下-上或下-上-下手势（至少3次交替）

## 故障排除

### 常见问题
1. **传感器初始化失败**
   - 检查I2C连接是否正确
   - 确认电源供电正常
   - 检查I2C地址是否冲突

2. **手势识别不敏感**
   - 调整手掌与传感器的距离（建议5-15cm）
   - 确保手势动作清晰、速度适中
   - 避免强光直射传感器

3. **连续手势识别失败**
   - 确保手势动作有明显的方向变化
   - 手势速度不要过快或过慢
   - 每个手势之间要有短暂停顿

### 调试参数
可以在`gesture_sensor.h`中调整以下参数：
- `SEQUENCE_TIMEOUT_MS`：连续手势超时时间（默认2000ms）
- `MIN_SEQUENCE_COUNT`：最小连续手势次数（默认3次）
- 检测任务延迟：50ms（在GestureTaskFunction中）

## 扩展功能
如需添加更多手势或修改动作映射，可以在`ProcessGesture()`方法中添加新的case分支，或在`CheckSequentialGestures()`中实现更复杂的手势序列识别。
